The numbers of NosTale: one service per curve or table, for experience, HP and MP, damage, defence, dodge, hit rate,
reputation, upgrades and the rest. Any value that scales with a level or a stat belongs here rather than in the server.

## Install

```bash
dotnet add package NosCore.Algorithm
```

## Usage

Each curve is an `I<Thing>Service` with its `<Thing>Service` implementation, ready to register in a container:

```csharp
using NosCore.Algorithm.ExperienceService;

IExperienceService experience = new ExperienceService();
long toLevelUp = experience.GetExperience(10);
```

The ceilings (maximum level, job level, hero level and so on) are in
[Constants.cs](src/NosCore.Algorithm/Constants.cs).

## Contributing

Questions, ideas and pull requests are welcome; most of the discussion happens on [Discord](https://discord.gg/Eu3ETSw).
Any editor that handles .NET 11 works: `dotnet build` and `dotnet test` run on Windows, Linux and macOS.
In Visual Studio, [Roslynator](https://github.com/dotnet/roslynator) and
[ReSharper](https://www.jetbrains.com/resharper/) help keep to the code style.
